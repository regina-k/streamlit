# ML 모델 발표 5분 대본

## 발표 기준

- 대상 슬라이드: `SLIDE 4`, `SLIDE 4-1`, `SLIDE 4-2`
- 예상 시간: 약 5분
- 대괄호 안 문구는 발표 동작과 시간 안내이므로 읽지 않는다.
- MAE와 RMSE는 `%`가 아니라 상승률의 `%p`로 읽는다.

## 발표 전 슬라이드 수정

`SLIDE 4`의 `예측 기간 1개월-61개월 사이의 값 (2021.06.-2026.06.)`은 관측 기간과 예측기간을 혼동한 표현이다. 다음처럼 고친다.

> 월별 관측 기간: 2021.06~2026.06  
> 학습 예측기간: 12·24·36·48·60개월  
> 서비스 제공: 12·36·60개월

## 발표 대본

### 도입 (0:00~0:20)

지금부터 아파트 시세 상승률 예측 모델을 설명드리겠습니다. 저희의 목표는 오를 단지를 단순히 분류하거나 순위를 매기는 것이 아니라, 사용자가 선택한 특정 단지와 평형의 1년, 3년, 5년 뒤 KB 매매시세 상승률을 숫자로 제공하는 것입니다.

### SLIDE 4. 모델의 접근 방식과 feature (0:20~1:40)

[왼쪽의 핵심 접근 방식부터 오른쪽 feature 영역으로 이동한다.]

이 문제는 오를지 말지를 맞히는 분류가 아니라, 얼마나 오를지를 계산하는 연속형 회귀 문제로 정의했습니다. 기본 알고리즘은 LightGBM입니다. 가격, 면적, 연식, 거리처럼 형태가 다른 정형 데이터를 함께 다루기 좋고, 반복 실험과 서비스 추론이 빠르다는 점을 고려했습니다.

저희가 multi-horizon이라고 부르는 이유는 하나의 모델이 여러 예측기간을 처리하기 때문입니다. 1년용, 3년용, 5년용 모델을 따로 만든 것이 아니라, `horizon_months`라는 예측 개월 수를 입력해 같은 LightGBM으로 기간별 상승률을 계산합니다. 서비스에서는 12개월, 36개월, 60개월 결과를 제공합니다.

모델에는 네 종류의 정보가 들어갑니다. 첫째는 KB 매매·전세시세, 전세가율, 시세갭 같은 시장정보입니다. 둘째는 면적, 연식, 세대수, 용적률 같은 단지·평형 정보입니다. 셋째는 역, 학교, 병원까지의 거리와 주변 시설 수입니다. 마지막으로 평당가, 단지 내 면적·가격 순위, 같은 구 대비 가격 프리미엄 같은 파생 feature를 사용했습니다.

최종 데이터는 단지·평형·기준월·예측기간 단위로 약 203만 행이며, 6,297개 단지와 27,902개 단지·평형 조합을 포함합니다.

### SLIDE 4-1. ML 추론 파이프라인 (1:40~3:20)

[파이프라인을 사용자 입력부터 서비스 제공까지 순서대로 가리킨다.]

사용자가 단지와 평형을 선택하면 시스템은 해당 단지의 최신 KB 시세와 단지·입지 feature를 조회합니다. 그다음 ver9b single multi-horizon LightGBM이 기본 상승률을 계산합니다. 예측기간에 따라 별도 모델을 바꾸는 것이 아니라, `horizon_months` 값만 바꿔 같은 모델을 사용합니다.

기본 예측 뒤에는 최종 ver16 residual 보정이 적용됩니다. 쉽게 말하면 특정 단지와 평형에서 과거에 반복적으로 발생했던 예측 오차를 한 번 더 반영하는 과정입니다. 예를 들어 기본 모델이 어떤 평형을 계속 실제보다 2%p 낮게 예측했다면, 최근 검증 데이터에서 확인한 오차를 참고해 기본 예측을 보정합니다.

다만 관측값이 한두 건뿐인 평형의 오차를 그대로 믿으면 과도한 보정이 될 수 있습니다. 그래서 데이터가 적으면 같은 단지, 같은 구의 비슷한 면적, 같은 예측기간의 평균 오차를 참고합니다. 보정값은 최근 validation 데이터로 미리 계산해 저장하며, 사용자가 요청할 때 모델을 다시 학습하는 방식은 아닙니다.

최종 화면에는 예상 상승률과 이를 현재 시세에 적용한 추정 시세를 보여줍니다. 여기에 과거 test에서 관측한 P80·P90 오차 범위와 confidence도 함께 표시합니다. 예측값 하나를 확정적인 미래 가격으로 받아들이지 않도록 하기 위한 장치입니다.

### SLIDE 4-2. 개선 과정과 최종 성능 (3:20~4:40)

[그래프의 ver1에서 ver16 방향으로 이동한다.]

세로축은 Test MAE이며 낮을수록 좋습니다. 최종 MAE 5.04%p는 예측 상승률과 실제 상승률의 차이가 평균적으로 약 5.04%p였다는 뜻입니다.

초기 구 단위 모델은 9.41%p였고, 입지 feature만 추가했을 때는 개선이 제한적이었습니다. ver7d는 12개월 전용 모델이라 7.12%p까지 낮아졌지만, 1년·3년·5년을 하나의 구조로 제공하려는 서비스 목적과는 달랐습니다. 그래서 ver9b에서 single multi-horizon 구조를 기준 모델로 확정했습니다.

그 이후에는 모델을 계속 바꾸기보다 단지와 평형에 남은 반복 오차를 보정했습니다. 단지 단위, 데이터가 부족한 경우의 넓은 집단 평균, 평형 단위 보정을 차례로 적용하면서 오차를 줄였습니다. ver14는 test 수치는 좋아 보였지만 별도의 rolling holdout에서 안정성이 재현되지 않아 최종 후보에서 제외했습니다.

최종 ver16은 Test MAE 5.0376%p, RMSE 8.1711%p, R 제곱 0.7150, Spearman 0.8715를 기록했습니다. 동일한 multi-horizon 기준 모델인 ver9b와 비교하면 MAE를 약 38.8% 줄였습니다.

### 결론 (4:40~5:00)

정리하면, 저희는 하나의 LightGBM으로 여러 예측기간을 처리하는 구조를 먼저 만들고, 단지·평형에서 반복되는 오차를 보수적으로 보정해 개별 예측 성능을 높였습니다.

다만 5년 예측은 충분한 test 기간이 확보되지 않아 낮은 신뢰도로 제공합니다. 따라서 이 모델은 미래 가격의 정답이 아니라, 예상 상승률과 오차 가능성을 함께 보여주는 의사결정 보조 도구로 해석해야 합니다. 감사합니다.

## 반드시 기억할 표현

- `multi-horizon`은 여러 값을 한 번에 출력한다는 뜻이 아니라, 같은 모델에 예측 개월 수를 넣어 여러 기간을 처리한다는 뜻이다.
- `5.0376%p`는 정확도가 아니라 평균 절대오차다.
- `38.8% 개선`은 비교 가능한 multi-horizon 기준 모델 `ver9b` 대비 수치다.
- P80/P90은 정식 신뢰구간이 아니라 과거 test 오차 기준의 참고 범위다.
- 60개월 예측은 inference 가능하지만 검증 기간이 부족해 `low confidence`다.
