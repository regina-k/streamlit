# 부동산 분석 및 대출 제안 서비스 PRD

## 1. 목적

사용자가 보유 아파트와 관심 아파트를 입력하면, 단지별 가격 상승률 예측, 대출 가능성, 필요 자기자금, 관련 대출 상품과 부동산 정책 정보를 한 화면에서 확인할 수 있는 Streamlit 기반 의사결정 보조 서비스를 만든다.

## 2. 핵심 사용자 시나리오

1. 사용자는 현재 보유 아파트를 검색하고 매수 시점, 매수가, 현재 KB 시세를 입력한다.
2. 사용자는 가구 형태, 매매 목적, 가용자본금, 연소득, 기존 대출을 입력한다.
3. 사용자는 지역, 가격대, 면적, 평형 조건으로 갈아타기 후보 단지를 탐색한다.
4. 사용자는 후보 단지를 선택하고 1년/3년/5년 예상 상승률과 대출 가능성을 확인한다.
5. 사용자는 AI 어드바이저를 통해 대출 상품, 정책, 단지 관련 질문에 대한 문서 기반 답변을 받는다.

## 3. 주요 기능 요구사항

### 3.1 단지 검색 및 후보 탐색

- 단지명 검색은 사용자의 입력어와 유사한 단지를 보여준다.
- 지역 검색은 선택 지역의 단지를 필터링한다.
- 후보 목록은 가격, 필요 자기자금, 최근 상승률, 예측 상승률 기준으로 정렬할 수 있어야 한다.
- 후보 단지 선택 시 상세 정보, 가격 정보, 실거래 추이, ML 예측 결과를 확인할 수 있어야 한다.

### 3.2 사용자 재무 정보 입력

- 입력 항목은 가구 형태, 매매 목적, 가용자본금, 부부합산 연소득, 현재 보유 대출이다.
- 희망 지역과 희망 평형을 선택할 수 있어야 한다.
- 입력값은 대출 한도, DSR, 필요 자기자금 계산에 사용한다.

### 3.3 ML 가격 상승률 예측

- 단지/평형 단위의 최신 데이터를 기준으로 1년, 3년, 5년 상승률을 예측한다.
- 결과는 상승률, 추정 시세, 신뢰도, 모델 버전을 함께 표시한다.
- 기본 모델은 다중 horizon 입력을 지원하는 `ver16_hierarchical_apt_size_residual`을 사용한다.

### 3.4 대출 분석 및 상품 제안

- 선택 단지의 매매가 기준으로 최대 대출 한도, LTV, DSR, 필요 자기자금을 계산한다.
- 사용자의 가구 형태와 매매 목적에 따라 검토할 만한 대출 상품 정보를 제시한다.
- 상품 상세 외부 링크 연결은 선택 기능이며, 실제 상품 DB/API 연동이 필요하다.

### 3.5 RAG 기반 AI 어드바이저

- 신한은행 주택담보대출 FAQ와 부동산 규제 문서를 기반으로 답변한다.
- 사용자는 단지, ML 예측, 대출 상품, 정책 관련 질문을 할 수 있어야 한다.
- FAISS 벡터스토어가 없을 때는 앱이 중단되지 않고 생성 안내를 표시한다.

## 4. 데이터와 산출물

- 아파트 원천/전처리 데이터: `data/apartment/`
- 학교, 역, 병원 입지 원천/전처리 데이터: `data/additional/`
- 입지 전처리 CSV: `data/additional/preprocessed/school.csv`, `station.csv`, `hospital.csv`
- ML 통합 feature store: `data/integration/`
- RAG 원천 문서: `data/rag_docs/`
- RAG 벡터스토어 산출물: `vector_store/shinhan_faiss/`
- 모델 및 실험 산출물: `ml_model/outputs/`

`data/apartment/`, `data/additional/`, `data/integration/`, `vector_store/`, `ml_model/outputs/`의 대용량 산출물은 Git에 올리지 않는다. 단, `data/rag_docs/`의 원천 문서는 RAG 재현을 위해 Git에 포함한다.

## 5. 비기능 요구사항

- 앱은 `streamlit run app.py`로 실행 가능해야 한다.
- 의존성은 `requirements.txt`에 버전 고정 상태로 관리한다.
- OpenAI API Key가 없어도 기본 검색, ML 예측, 대출 계산 기능은 동작해야 한다.
- FAISS 인덱스가 없어도 RAG 영역은 생성 안내를 보여주고 앱 전체를 중단하지 않아야 한다.
- 새로운 모델 실험이나 feature engineering은 `ml_model/outputs/performance/VERSION_LOG.md`와 관련 Markdown 보고서를 갱신해야 한다.
