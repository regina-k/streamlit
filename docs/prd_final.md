# AI 기반 부동산 분석 및 대출 제안 서비스 최종 PRD

## 1. 문서 목적

본 문서는 현재 구현된 Streamlit 서비스를 기준으로 작성한 최종 PRD이다. 서비스의 목적, 사용자 흐름, 핵심 기능, 데이터·모델 구성, 실행 조건을 한 문서에서 확인할 수 있도록 정리한다.

## 2. 서비스 개요

본 서비스는 서울 아파트 단지·평형 데이터를 기반으로 사용자의 매수 또는 갈아타기 의사결정을 돕는 부동산 분석 서비스이다. 사용자는 자신의 자금 조건과 관심 단지를 입력하고, 단지별 가격 상승률 예측, 대출 가능성, 필요 자기자금, 보유 주택 매도 후 자금 여력, 문서 기반 AI 상담 결과를 한 화면 흐름으로 확인할 수 있다.

서비스는 단순 추천이나 랭킹보다, 사용자가 선택한 개별 단지에 대해 “이 집을 살 수 있는지”, “향후 상승률은 어느 정도로 예측되는지”, “대출과 자기자금 관점에서 무리가 없는지”를 설명하는 데 초점을 둔다.

## 3. 대상 사용자와 문제 정의

### 3.1 대상 사용자

- 서울 아파트 매수를 검토하는 개인 사용자
- 현재 보유 주택에서 다른 주택으로 갈아타기를 고민하는 사용자
- 대출 한도와 필요 자기자금을 함께 고려해야 하는 사용자
- 단지별 미래 상승률과 금융 조건을 함께 보고 싶은 사용자

### 3.2 해결하려는 문제

- 아파트 가격, 대출 조건, 보유 주택 자금, 정책 문서가 분리되어 있어 사용자가 스스로 판단하기 어렵다.
- 단지별 미래 상승률은 직관적으로 비교하기 어렵고, 장기 예측은 불확실성을 함께 보여줄 필요가 있다.
- 대출 가능 여부는 단순 매매가뿐 아니라 사용자 소득, 기존 대출, 가용자금, 보유 주택 매도 자금을 함께 봐야 한다.
- 문서 기반 상담은 사용자가 입력한 맥락과 연결되어야 초개인화된 답변이 가능하다.

## 4. 핵심 사용자 흐름

1. 사용자는 `내 투자 프로파일` 탭에서 가구 형태, 매수 목적, 가용자금, 연소득, 기존 대출을 입력한다.
2. 보유 주택이 있는 사용자는 선택 입력 영역에서 보유 주택 현재 시세, 매수가, 매수 시점 등을 입력한다.
3. 사용자는 `단지 탐색` 탭에서 지역, 단지명, 가격, 세대수, 면적 조건으로 후보 단지를 검색한다.
4. 후보 단지에 대해 1년 AI 예측 상승률, 필요 자기자금, 자금 여유를 확인한다.
5. 사용자는 관심 단지·평형을 선택한다.
6. `AI 종합 분석` 탭에서 선택 단지의 1년·3년·5년 상승률 예측, 추정 시세, confidence, error band를 확인한다.
7. 서비스는 사용자의 자금 조건을 바탕으로 대출 한도, LTV, DSR, 필요 자기자금, 잔여/부족 자금을 계산한다.
8. 보유 주택 정보가 있으면 `가용자금 + 보유주택 매도 후 자기자본` 기준으로 갈아타기 가능 여부를 보여준다.
9. 사용자는 AI 어드바이저에게 질문하거나 빠른 질문을 선택해 신한은행 문서 기반 상담 리포트를 받는다.

## 5. 주요 기능 요구사항

### 5.1 사용자 프로파일 입력

- 사용자는 가구 형태, 매수 목적, 가용자금, 연소득, 기존 대출을 입력할 수 있어야 한다.
- 보유 주택 정보는 선택 입력으로 제공한다.
- 보유 주택을 입력하지 않아도 기본 단지 탐색, ML 예측, 대출 계산은 가능해야 한다.
- 입력된 프로파일은 단지 탐색, 대출 계산, AI 상담 프롬프트에 전달되어야 한다.

### 5.2 단지 탐색

- 사용자는 지역, 단지명, 가격대, 세대수, 면적 조건으로 서울 아파트 단지를 필터링할 수 있어야 한다.
- 단지명 검색은 표기 차이나 일부 입력을 고려해 유사 단지를 찾을 수 있어야 한다.
- 검색 유사도는 내부 정렬에만 사용하고 화면에는 노출하지 않는다.
- 사용자는 후보 단지 중 하나를 선택할 수 있어야 하며, 선택 결과는 AI 종합 분석 탭으로 전달되어야 한다.
- 후보 목록에는 매매시세, 전세시세, 세대수, 준공 정보, 필요 자기자금, 1년 예측 상승률 등 의사결정에 필요한 항목을 표시한다.

### 5.3 ML 가격 상승률 예측

- 단지 ID와 평형 ID 기준으로 1년, 3년, 5년 상승률을 예측한다.
- 최종 모델은 `ver16_hierarchical_apt_size_residual`을 사용한다.
- 모델은 하나의 LightGBM 기반 multi-horizon 구조로, `horizon_months` 입력값에 따라 12개월, 36개월, 60개월 예측을 수행한다.
- 예측 결과는 상승률, 추정 시세, 모델 버전, confidence, 경험적 오차 범위와 함께 표시한다.
- 60개월 예측은 데이터 제약으로 낮은 confidence 또는 fallback 결과가 나올 수 있음을 표시한다.

### 5.4 대출 분석

- 선택 단지 매매가와 사용자 프로파일을 기준으로 대출 한도, LTV, DSR, 필요 자기자금을 계산한다.
- 계산 결과는 실제 심사 확정값이 아니라 의사결정 보조용 추정치로 표시한다.
- 사용자의 가용자금과 필요 자기자금을 비교해 자금 여유 또는 부족액을 보여준다.
- 보유 주택이 있는 경우, 보유 주택 현재 시세에서 기존 대출을 뺀 값을 매도 후 자기자본으로 계산한다.
- 갈아타기 가능 여부는 `가용자금 + 보유주택 매도 후 자기자본 - 필요 자기자금` 기준으로 판단한다.

### 5.5 대출 상품 안내

- 사용자 조건과 선택 단지를 기준으로 검토 가능한 주택담보대출 상품을 안내한다.
- 상품 정보는 신한은행 문서와 서비스 내 규칙 기반 계산을 함께 활용한다.
- 실제 상품 신청 가능 여부, 금리, 한도는 은행 공식 채널 확인이 필요하다는 안내를 포함한다.

### 5.6 RAG 기반 AI 종합 상담

- AI 상담은 GPT-5.5와 FAISS 기반 RAG 구조를 사용한다.
- RAG 원천 문서는 신한은행 주택담보대출 관련 문서와 부동산 정책 문서를 사용한다.
- 상담 프롬프트에는 사용자 프로파일, 보유 주택 정보, 선택 단지 정보, ML 예측 결과, 대출 계산 결과, 검색 조건이 포함되어야 한다.
- 정보가 없는 항목은 임의 추정하지 않고 `없음` 또는 확인 필요로 표현한다.
- FAISS 인덱스가 없거나 OpenAI API Key가 없을 때도 앱 전체가 중단되지 않고 안내 또는 fallback 답변을 제공해야 한다.

- 대용량 데이터, 모델 바이너리, FAISS 인덱스는 Git에 포함하지 않는다.
- RAG 원천 문서인 `data/rag_docs/`는 재현성을 위해 Git에 포함한다.
- 데이터가 없는 환경에서는 `docs/capture/`의 화면 캡쳐로 서비스 흐름을 확인할 수 있어야 한다.

## 7. 모델 및 평가 요구사항

- 모델은 단지·평형 단위 상승률 예측을 목표로 한다.
- 평가 방식은 랜덤 분할이 아니라 시간 순서 기반 holdout을 사용한다.
- 각 horizon에서 라벨이 존재하는 최근 5개월을 test, 직전 5개월을 validation으로 사용한다.
- validation residual을 활용해 최종 예측값을 계층형으로 보정한다.
- 주요 성능 지표는 MAE, RMSE, R², Spearman, P80/P90 절대오차를 사용한다.
- 현재 최종 모델 test MAE는 약 `5.0376%p`이며, 이는 상승률 percentage point 기준 평균 절대오차이다.

## 8. 비기능 요구사항

- 서비스는 `streamlit run app.py`로 실행 가능해야 한다.
- 의존성은 `requirements.txt`에 버전 고정 상태로 관리한다.
- `.env`에는 API Key 등 비밀값만 두고, 모델 설정은 코드/config 기본값으로 관리한다.
- OpenAI API Key가 없어도 단지 검색, ML 예측, 대출 계산은 동작해야 한다.
- 오류 발생 시 앱 전체가 중단되지 않고 사용자가 이해할 수 있는 안내를 제공해야 한다.
- 화면 캡쳐, README, 모델 문서, 기능 구현 현황표를 통해 비개발자도 서비스 흐름을 확인할 수 있어야 한다.

## 10. 현재 구현 범위와 제한사항

### 구현 완료

- 사용자 프로파일 입력
- 보유 주택 선택 입력 및 갈아타기 자금 계산
- 서울 아파트 단지 검색과 필터링
- 후보 단지 1년 AI 예측 상승률 계산
- 선택 단지 1년·3년·5년 ML 상승률 예측
- 대출 한도, LTV, DSR, 필요 자기자금 계산
- 신한은행 문서 기반 RAG 상담
- GPT-5.5 기반 개인화 AI 리포트
- 서비스 흐름 캡쳐 문서화

### 제한사항

- 대출 계산은 실제 금융 심사 결과가 아닌 추정치이다.
- 세금, 중개수수료, 실제 상환 조건, 개인 신용 상태는 정밀 반영하지 않는다.
- 60개월 상승률 예측은 데이터 기간 한계로 confidence가 낮을 수 있다.
- RAG 답변은 제공된 문서 범위 안에서만 근거를 가진다.
- 실시간 부동산 시세 API나 실시간 금융 상품 API와 직접 연동된 상태는 아니다.

## 11. 성공 기준

- 사용자가 프로파일 입력부터 단지 선택, ML 예측, 대출 분석, AI 상담까지 하나의 흐름으로 수행할 수 있다.
- 선택한 단지 정보와 사용자 프로파일이 AI 상담에 반영된다.
- 보유 주택이 있는 경우 갈아타기 가능 여부가 보유 주택 매도 후 자금까지 고려해 계산된다.
- 데이터와 모델 산출물을 정해진 경로에 복원하면 다른 환경에서도 동일한 서비스 흐름을 재현할 수 있다.
- 데이터가 없는 환경에서도 캡쳐 문서를 통해 서비스 결과물을 설명할 수 있다.
