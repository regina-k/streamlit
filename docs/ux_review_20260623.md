# Streamlit UX 점검 기록

## 점검 일시

- 2026-06-23
- 대상: `http://localhost:8510`
- 방법: Streamlit 로컬 실행 후 Playwright로 탭, 검색, 계산, 정렬 흐름 직접 확인

## 사용자 관점 관찰

### 1. 첫 탭이 단지 탐색으로 시작함

현재 첫 화면은 `단지 탐색`이다. 하지만 서비스의 핵심은 개인의 자본, 소득, 보유 대출, 매수 목적을 기준으로 갈아타기 가능성을 판단하는 것이다. 사용자는 먼저 자기 조건을 입력하고, 그 다음 단지를 고르는 편이 자연스럽다.

개선 방향:

- `내 투자 프로파일`을 1번 탭으로 이동한다.
- `단지 탐색`은 2번 탭으로 이동한다.
- 안내 문구도 새 탭 순서에 맞춘다.

### 2. 후보별 AI 계산 범위와 정렬 기대가 다름

`래미안` 검색 후 후보가 905개로 줄어들면 `AI 상승률 계산` 버튼이 열린다. 버튼을 누르면 현재 화면 기준 상위 5개 후보만 계산된다. 이후 사용자가 `매매시세 높은 순` 같은 다른 정렬을 누르면 계산하지 않은 후보가 위로 올라오고, 사용자는 방금 계산했는데도 `계산 전`이 다시 보인다고 느낀다.

개선 방향:

- 후보 목록의 AI 계산은 "전체 후보 계산"처럼 보이면 안 된다.
- 계산 대상은 별도 "AI 예측 후보만 보기" 또는 "현재 화면 상위 후보 계산"처럼 분명히 설명해야 한다.
- 정렬을 바꿔도 계산된 후보가 사라지지 않도록, 계산된 후보만 모아 보는 모드를 제공한다.
- `AI예측 높은 순` 정렬은 계산된 값이 있을 때만 의미가 있으므로 계산 전에는 안내를 강화한다.

### 3. 행 선택 후 상세 정보가 약함

테이블에서 한 후보를 선택하면 기본 단지 정보와 대출 분석은 보이지만, 사용자가 가장 궁금해할 1년/3년/5년 예측이 같은 상세 영역에서 바로 비교되지 않는다. 현재는 Tab 3로 넘어가야 종합 예측 흐름을 볼 수 있어 후보 탐색 중 맥락이 끊긴다.

개선 방향:

- `선택된 타겟 단지` 영역에 세부 정보 카드를 강화한다.
- 선택 단지 기준 1년/3년/5년 예상 상승률과 추정 시세를 보여준다.
- 예측 신뢰도, 모델 버전, 오차 범위도 너무 깊게 숨기지 않고 간결하게 표시한다.

### 4. 사이드바 입력과 검색 유사도 노출이 흐름을 흐림

보유 주택 선택, 매수 시점, 매수가가 사이드바에 남아 있어 사용자는 왼쪽 입력과 1번 탭의 프로파일 입력이 별도 기능처럼 느낄 수 있다. 또한 단지 탐색 표의 `검색유사도` 점수는 내부 후보 정렬에는 유용하지만 사용자에게는 모델 점수처럼 보여 해석 부담을 만든다.

개선 방향:

- 사이드바는 실행 상태와 AI 연결 상태 확인 정도로 축소한다.
- 보유 주택 검색, 매수 시점, 매수가는 `내 투자 프로파일` 탭으로 이동한다.
- `검색유사도`는 내부 검색/정렬 로직에만 사용하고 결과 표에는 노출하지 않는다.
- 사용자가 직접 선택할 정렬명은 `검색유사도 높은 순` 대신 `이름이 비슷한 순`처럼 행동 중심 문구로 표현한다.

## 우선 개선 항목

1. 탭 순서를 `내 투자 프로파일` → `단지 탐색` → `AI 종합 분석`으로 변경.
2. 단지 탐색 가이드와 Tab 3 사전 안내 문구를 새 탭 순서에 맞게 수정.
3. 후보 AI 계산 후 `AI 계산 후보만 보기` 토글을 제공해 정렬 변경 시 `계산 전` 행이 위로 올라오는 혼란을 줄임.
4. 선택 단지 상세 영역에 1년/3년/5년 예측 카드 추가.
5. 보유 주택/매수 정보 입력을 `내 투자 프로파일` 탭으로 이동하고, 단지 탐색 표의 `검색유사도` 컬럼은 숨김.
